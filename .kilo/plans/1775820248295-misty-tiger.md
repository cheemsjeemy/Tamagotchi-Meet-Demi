# Physical Button Controller Integration Plan

## Hardware Pin Mapping

| Button | GPIO Pin | Active State |
|--------|----------|-------------|
| RB     | 4        | HIGH       |
| Right  | 5        | HIGH       |
| Down   | 6        | HIGH       |
| Center | 7        | HIGH       |
| Up     | 15       | HIGH       |
| Left   | 16       | HIGH       |
| LB     | 17       | HIGH       |

**Pull-down config**: Pins are HIGH by default, button press pulls to GND (detected as LOW).

---

## Button Functions

### Standard Mode (No Modifier Held)

| Button | Function |
|--------|----------|
| Up     | Page Up (fast scroll up through lists) |
| Down   | Page Down (fast scroll down through lists) |
| Left   | Slider - (decrease value / seek backward) |
| Right  | Slider + (increase value / seek forward) |
| Center | Select / Play / Pause (primary action) |
| LB     | **Shift/Modifier** (hold to activate alternate functions) |
| RB     | Menu (press to enter menu from idle) |

### Modifier Mode (Hold LB)

| Button | Function |
|--------|----------|
| Up     | Special move / interaction |
| Down   | Alternative action |
| Left   | "A" action (game) |
| Right  | "B" action (game) |
| Center | Alternative action |
| RB     | Secondary action |

### Idle State

| Button | Function |
|--------|----------|
| RB     | Enter Menu directly |
| Center | Play / Pause (if media app) |

## Implementation Steps

### 1. Replace Touch Input Code
- Remove touch-related code in `main.cpp`:
  - Remove `#define TOUCH_PIN_*` definitions
  - Remove `touchRead()` calls
  - Remove `TOUCH_THRESHOLD` constant
- Add GPIO definitions with button pins

### 2. Update Input Reading
- Replace `touchRead()` with `digitalRead()` in `mainLoopTask()`
- Add pin mode configuration in `initButtons()` using `pinMode(pin, INPUT_PULLDOWN)`
- Rename variables from `touchState_*` to `btnState_*`

### 3. Update Input Handling (handleMenuInput)
- **Up** = Page Up (fast scroll) - scroll multiple items per press
- **Down** = Page Down (fast scroll) - scroll multiple items per press
- **Left** = Slider - (decrease value)
- **Right** = Slider + (increase value)
- **Center** = Enter / Select
- **Right alone** from idle = Enter Menu (same as old RB)
- Add LB modifier detection (hold LB to enable alternate mappings)

### 4. Add LB Modifier Logic
- Track LB hold state separately
- When LB held, map buttons to modifier functions
- Add visual feedback when modifier active (optional: beep or display indicator)

### 5. Simplify Menu Enter
- Single button: RB enters menu directly
- Remove old Down+Center combo

## Code Changes Required

### In `main.cpp`:

1. **Definitions** (replace touch defines):
```cpp
#define BTN_RB 4
#define BTN_RIGHT 5
#define BTN_DOWN 6
#define BTN_CENTER 7
#define BTN_UP 15
#define BTN_LEFT 16
#define BTN_LB 17
```

2. **Variable names** (rename for clarity):
```cpp
// Rename from touchState_* to btnState_*
bool btnState_UP = false;
bool prevBtnState_UP = false;
// ... etc
bool btnState_LB = false;     // NEW - modifier key
bool prevBtnState_LB = false;
```

3. **Init function** (rename and update):
```cpp
void initButtons() {
    pinMode(BTN_RB, INPUT_PULLDOWN);
    pinMode(BTN_RIGHT, INPUT_PULLDOWN);
    pinMode(BTN_DOWN, INPUT_PULLDOWN);
    pinMode(BTN_CENTER, INPUT_PULLDOWN);
    pinMode(BTN_UP, INPUT_PULLDOWN);
    pinMode(BTN_LEFT, INPUT_PULLDOWN);
    pinMode(BTN_LB, INPUT_PULLDOWN);
    Serial.println("Buttons initialized: GPIO 4=RB, 5=Right, 6=Down, 7=Center, 15=Up, 16=Left, 17=LB");
}
```

4. **Input reading** (replace touch with digital):
```cpp
// OLD:
touchState_UP = touchRead(TOUCH_PIN_UP) > TOUCH_THRESHOLD;

// NEW:
btnState_UP = digitalRead(BTN_UP) == HIGH;
btnState_LB = digitalRead(BTN_LB) == HIGH;  // Modifier check
```

5. **Modifier tracking** (add new variable):
```cpp
bool lbModifierActive = false;
bool prevLbModifierActive = false;
```

6. **Menu enter** (simplify):
```cpp
// OLD: Check Down + Center combo
// NEW: Single button
if (currentState == STATE_IDLE && btnState_RB) {
    if (millis() - systemBootTime >= MENU_ENTER_DELAY_MS) {
        beepC5(80);
        setState(STATE_MENU);
    }
}
```

7. **handleMenuInput update**:
- Up = menuPageUp() (new function for fast scroll)
- Down = menuPageDown() 
- Left = adjustValue(-1)
- Right = adjustValue(+1)
- LB = modifier enable (check held state)
- When LB held: remap button functions to special actions
