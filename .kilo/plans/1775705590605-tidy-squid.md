# Plan: Buzzer Handler Module

## Goal
Create a buzzer handler module where:
- `Sing.h` = song data only (library of songs with notes + duration + BPM)
- `buzzer.h` = buzzer logic with `playSong("SongName")` that fetches from Sing.h

---

## Data Structure

### Duration in Beat Fractions
- 1.0 = quarter note (one beat)
- 0.5 = eighth note (half beat)
- 0.25 = sixteenth note (quarter beat)
- 2.0 = half note (two beats)

### Conversion Formula
```
milliseconds = (duration / bpm) * 60000
// Example: bpm=120, duration=1.0 → (1/120)*60000 = 500ms
```

### Rest Handling
- pitch = 0 means rest (silence, just wait for duration)

### 2. Create `src/miscellaneous/buzzer.h` (Handler with State Machine)

#### Playback States
```
enum class PlayState {
    STOPPED,  // Not playing
    PLAYING,  // Actively playing notes
    PAUSED    // Playback paused
};
```

#### Buzzer Class Features
- **Non-blocking**: Uses `millis()` timing, not `delay()`
- **State machine**: STOPPED → PLAYING → PAUSED → PLAYING
- **Control methods**:
  - `play(songName)` - Start playing a song by name
  - `pause()` - Pause current playback (saves current note index)
  - `resume()` - Resume from paused state
  - `restart()` - Start song from beginning
  - `stop()` - Stop completely, reset to beginning

#### Internal State Variables
```cpp
private:
    String currentSongName;
    int currentNoteIndex;
    PlayState state;
    unsigned long noteStartTime;
    bool isPlayingNote;
```

#### Playback Logic (in buzzer.cpp `update()`)
1. If state is STOPPED or song empty → do nothing
2. If state is PLAYING:
   - If not currently playing a note → start next note (or rest)
   - If note duration elapsed → move to next note
   - If end of song → set state to STOPPED
3. If state is PAUSED:
   - Do nothing, just wait for resume

#### Timing Calculation
```cpp
// Convert beat fraction to milliseconds
int ms = (note.duration / bpm) * 60000;
```

#### MIDI to Frequency
```cpp
// f = 440 * 2^((note-69)/12)
int freq = 440 * pow(2, (midiNote - 69) / 12.0);
```

## Usage Example

```cpp
// In main.cpp
#include "miscellaneous/buzzer.h"

Buzzer buzzer(BUZZER_PIN);

// In loop()
buzzer.update();  // Call every iteration for non-blocking playback

// Control playback
buzzer.play("ABC Song");    // Start playing
buzzer.pause();             // Pause at current note
buzzer.resume();            // Continue from paused position
buzzer.restart();           // Start from beginning
buzzer.stop();              // Stop and reset
```
