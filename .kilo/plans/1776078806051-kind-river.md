## Goal
Add core Tamagotchi gameplay + basic AI mood system to existing Demi code **without breaking anything**.

## 1. Stats System

Keep existing stats: `hunger`, `happiness`, `energy`, `health`, `cleanliness` (all start at 100)

### Stat Depletion
```cpp
// Run every 5 seconds
hunger      = max(0, hunger - 1);
happiness   = max(0, happiness - 1);
energy      = max(0, energy - 1);
cleanliness = max(0, cleanliness - 1);

// Health = average of others
health = (hunger + happiness + energy + cleanliness) / 4;
```

## 2. AI Mood System

Simple state machine that tracks:
- `consecutiveCares` — how many actions in a row without low stats
- `neglectCount` — times stats got critical without care
- `lastMood` — previous mood for comparison

```cpp
enum DemiMood {
    MOOD_HAPPY,      // All stats > 70
    MOOD_CONTENT,    // All stats > 50
    MOOD_NEUTRAL,    // Mixed
    MOOD_CONCERNED,  // Any stat < 40
    MOOD_SAD,        // Any stat < 25
    MOOD_CRITICAL,   // Any stat < 15
    MOOD_SPOOKED,    // WiFi scare (future)
    MOOD_EXCITED,    // High happiness + recent care
    MOOD_TIRED,      // Energy < 30
    MOOD_HUNGRY,     // Hunger < 30
    MOOD_DIRTY,      // Cleanliness < 30
    MOOD_SLEEPY      // isSleeping
};

DemiMood getDemiMood() {
    if (isSleeping) return MOOD_SLEEPY;
    if (energy < 30) return MOOD_TIRED;
    if (hunger < 30) return MOOD_HUNGRY;
    if (cleanliness < 30) return MOOD_DIRTY;
    if (hunger < 15 || happiness < 15 || energy < 15 || cleanliness < 15) return MOOD_CRITICAL;
    if (hunger < 40 || happiness < 40 || energy < 40 || cleanliness < 40) return MOOD_CONCERNED;
    if (aiState.neglectCount >= 3) return MOOD_SAD;
    if (aiState.consecutiveCares >= 5 && happiness > 70) return MOOD_EXCITED;
    if (happiness >= 80 && health >= 80) return MOOD_HAPPY;
    if (health >= 50) return MOOD_CONTENT;
    return MOOD_NEUTRAL;
}
```

### AI State Tracking

```cpp
struct DemiAI {
    int consecutiveCares;    // Good care streak
    int neglectCount;         // Times ignored when critical
    int totalCares;           // Lifetime actions
    unsigned long lastCareTime; // When last fed/played
};

DemiAI ai = {};

// Update after each action
void onCareAction() {
    ai.consecutiveCares++;
    ai.totalCares++;
    ai.lastCareTime = millis();
    saveAI();
}

// Update when stats critical but no care
void checkNeglect() {
    if ((hunger < 20 || happiness < 20) && 
        (millis() - ai.lastCareTime > 300000)) { // 5 min no care
        ai.neglectCount++;
        ai.consecutiveCares = 0;
    }
}
```

## 3. Action Callbacks

| Action | Effect |
|--------|--------|
| Feed (any) | hunger +10 to +20, call `onCareAction()` |
| Petting | happiness +15, energy +5, call `onCareAction()` |
| Jumping | happiness +20, energy -10, call `onCareAction()` |
| Wash | cleanliness +30 |
| Sleep | isSleeping = true |

## 5. Persistence

```cpp
void saveAll() {
    Preferences prefs;
    prefs.begin("demi", false);
    prefs.putInt("hunger", hunger);
    prefs.putInt("happiness", happiness);
    prefs.putInt("energy", energy);
    prefs.putInt("health", health);
    prefs.putInt("cleanliness", cleanliness);
    prefs.putInt("consecutiveCares", ai.consecutiveCares);
    prefs.putInt("neglectCount", ai.neglectCount);
    prefs.putInt("totalCares", ai.totalCares);
    prefs.end();
}

void loadAll() {
    Preferences prefs;
    prefs.begin("demi", true);
    hunger = prefs.getInt("hunger", 100);
    happiness = prefs.getInt("happiness", 100);
    energy = prefs.getInt("energy", 100);
    health = prefs.getInt("health", 100);
    cleanliness = prefs.getInt("cleanliness", 100);
    ai.consecutiveCares = prefs.getInt("consecutiveCares", 0);
    ai.neglectCount = prefs.getInt("neglectCount", 0);
    ai.totalCares = prefs.getInt("totalCares", 0);
    prefs.end();
}
```
