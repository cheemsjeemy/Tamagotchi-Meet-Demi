# Horizontal Icon Menu Implementation Plan

## Overview
Implement horizontal scrolling icon menu for root-level navigation (Settings, Demi, Microsoft, Payloads) while keeping vertical navigation for sub-menus.

## Changes Required

### 1. Rename MS Auth to Microsoft
- File: `src/menu.cpp`
- Line 141: `menuMSAuth = menuFolder("MSAuth")` → `menuFolder("Microsoft")`
- Line 312: Update "MS Authenticator" display string to "Microsoft Authenticator"

### 2. Add Horizontal Navigation State to MenuState
- File: `src/menu.h`
- Add to `struct MenuState`:
  ```cpp
  uint8_t horizontalIndex;      // Current icon index (0-3 for root items)
  bool isHorizontalMenu;        // true = root level (horizontal), false = submenu (vertical)
  ```

### 3. Create Icon Mapping for Root Items
- File: `src/menu.cpp`
- Define root item array: `{&menuSettings, &menuDemi, &menuMicrosoft, &menuPayloads}`
- Map icons:
  - Settings: `u8g2_font_open_iconic_embedded_4x_t | 0x42` (big), `2x_t` (small)
  - Demi: Custom sprites from `MenuSprites.h` (DemiBig/DemiSmall)
  - Microsoft: Custom sprites from `MenuSprites.h` (MicrosoftBig/MicrosoftSmall)
  - Payloads: `u8g2_font_open_iconic_mime_4x_t | 0x43` (big), `2x_t` (small)

### 4. Modify renderMenu() for Horizontal Layout
- File: `src/menu.cpp`, ~line 1532
- When `menuState.isHorizontalMenu` is true:
  - Calculate 3 visible icons: left (index-1), center (index), right (index+1)
  - Display positions:
    - Left icon: x=5, 16x16px (small)
    - Center icon: x=48, 32x32px (big) with square highlight
    - Right icon: x=106, 16x16px (small)
  - Wrap around: last→first, first→last
  - Display name below center icon at y=50

### 5. Modify handleMenuInput() for Horizontal Navigation
- File: `src/menu.cpp`, ~lines 1165-1210
- When in horizontal menu:
  - LEFT button: decrement index (wrap to last)
  - RIGHT button: increment index (wrap to first)
  - CENTER/UP/DOWN: enter selected submenu (set `isHorizontalMenu = false`)
  - BACK (LB+RB): stay in horizontal mode (already there)

### 6. Add Navigation Sound
- File: `src/menu.cpp`
- In handleMenuInput(), call `beep(NOTE_B4, 30)` on LEFT/RIGHT navigation
- Use B note 4th octave (~247 Hz)

### 7. Preserve Sub-Menu Vertical Navigation
- When entering a submenu (Demi, Microsoft, Settings, Payloads):
  - Set `isHorizontalMenu = false`
  - Use existing vertical navigation logic
- When pressing BACK to return to root:
  - Set `isHorizontalMenu = true`
